
### **Example Commands You Can Run:**

**US Stocks:**

python main.py --market us --duration mid-2027 --output NVDA MSFT AMD

**Indian Stocks:**

python main.py --market india --duration "3 years" --output STLTECH MCX HAL

**Mixed Markets:**

python main.py --duration mid-2027 --output STLTECH:india MCX:india NVDA:us

**Individual Stocks:**

python main.py --market india --duration "3 years" --output STLTECH
